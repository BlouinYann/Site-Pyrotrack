01

Compatibilité & technique

PyroTrack System est développé et testé sous Windows 11. Le logiciel est également fonctionnel sous Windows 10. La compatibilité avec macOS et Linux n'est pas garantie à ce stade.

PyroTrack System est compatible avec tout adaptateur DMX disposant d'une entrée DMX (DMX In). Le logiciel prend également en charge les protocoles ArtNet et sACN en réception. Aucune marque spécifique n'est requise.

Non. PyroTrack System est un logiciel de lecture de trame DMX uniquement. Il reçoit le signal DMX provenant de votre console ou logiciel de pilotage pour en extraire les données de consommation. Il n'écrit pas de DMX et ne pilote pas d'appareils.

Non. Tout ce dont le logiciel a besoin est inclus dans l'installateur. Aucun téléchargement ou installation supplémentaire n'est nécessaire.

Le logiciel nécessite une source DMX active (USB, ArtNet ou sACN) pour que le suivi de consommation fonctionne. Sans signal entrant, la vue live ne recevra pas de données.

Oui. PyroTrack System supporte la gestion de plusieurs univers DMX simultanément via ArtNet et sACN.

02

Licence & version

La version gratuite est limitée à 10 fixtures, 20 minutes de calcul de consommation par session, et l'export PDF est désactivé. La version complète lèvera l'ensemble de ces limitations.

La licence peut être configurée par nombre de postes. Il est possible d'acquérir une licence pour un seul poste ou pour un nombre défini de machines selon vos besoins.

Oui. PyroTrack System fonctionne en mode hors ligne. L'activation de la licence nécessite une connexion internet, et une vérification périodique est effectuée lorsqu'une connexion est disponible. Le logiciel reste utilisable entre ces vérifications.

03

Fonctionnalités

PyroTrack System est conçu pour tout effet scénique ayant une consommation mesurable. Sont actuellement supportés : flame, smoke, CO₂, étincelles, bulles et confettis. Le logiciel ne se limite pas au pyrotechnique — tout effet FX avec consommation peut être suivi.

La version complète n'impose aucune limite sur le nombre de fixtures.

L'import MVR ou GDTF n'est pas disponible à ce stade. La gestion des fixtures se fait entièrement depuis le logiciel. Si un produit manque à la librairie, vous pouvez en faire la demande via la page contact en précisant le modèle souhaité.

Le format .pts (PyroTrack Session) est le format de fichier propriétaire de PyroTrack System. Il contient l'ensemble des données de votre projet : fixtures, groupes, historique de session. Il ne peut être ouvert que par PyroTrack System.

Pas encore. L'export PDF génère un rapport standardisé. La personnalisation (logo, en-tête) n'est pas disponible pour le moment.

04

Usage terrain

Oui. PyroTrack System a été utilisé et validé lors de sessions en conditions réelles de spectacle, sur laptop de scène.

Oui. PyroTrack System intègre une page web de monitoring accessible via mot de passe depuis n'importe quel appareil connecté au même réseau local. Cela permet à un opérateur secondaire (régie, plateau) de consulter la consommation en temps réel sans accéder au PC principal.

Non, il n'y a pas de mode multi-poste à proprement parler. Un seul PC fait tourner le logiciel. Les autres appareils du réseau peuvent uniquement consulter les données via la page web de monitoring (lecture seule).
